トラブルシューティング

LocalCompanion が動かない・調子が悪いときは、まずこのページをご確認ください。

起動しない

exe をダブルクリックしても何も起きない／すぐ閉じる

.NET 10 Desktop Runtime（x64）が未インストールの可能性があります。

  1. https://dotnet.microsoft.com/download/dotnet/10.0 を開きます。
  2. 「.NET Desktop Runtime」の x64 インストーラーをダウンロードして実行します。
  3. インストール後、LocalCompanion.exe をもう一度起動します。

起動はするがチャット画面が空／真っ白になる

Microsoft Edge WebView2 Runtime が未インストールの可能性があります（必須）。

会話ログの表示に WebView2 を使います。配布 ZIP には同梱していません。Windows 11 では通常 OS に含まれます。Edge 本体とは別コンポーネントです。

  1. https://developer.microsoft.com/microsoft-edge/webview2/ を開きます。
  2. Evergreen Bootstrapper または Evergreen Standalone Installer をダウンロードして実行します。
  3. インストール後、LocalCompanion.exe をもう一度起動します。

「アプリを開始できません」などのエラーが出る

  • Windows 10 1809（ビルド 17763）より古い OS では動作しません。Windows Update を適用してください。
  • 展開したフォルダーから en en-us ja などの言語フォルダーを削除した場合、起動できないことがあります。ZIP を展開し直してください。

SmartScreen の「Windows によって PC が保護されました」が出る

本アプリは現在コード署名を行っていないため、初回起動時に表示されることがあります。「詳細情報」→「実行」を選択すると起動できます。配布元から入手した ZIP かどうかをご確認ください。

初回セットアップが失敗する

初回セットアップ画面について

  • 初回は 言語選択 のあと、初回セットアップ 画面が表示されます。
  • 次へ（自動セットアップ） … llama.cpp の準備と、既定モデル Gemma 4 E2B（QAT） の取得を行います。
  • フォルダを選ぶ … お手持ちの GGUF フォルダを指定すると、既定モデルのダウンロードを省略できます（読み取り専用）。

llama.cpp / モデルのダウンロードに失敗する

  • 初回起動時はインターネット接続が必要です。
  • 短時間に何度も起動し直すと、ダウンロード元の制限（403 エラー）にかかることがあります。1 時間ほど待ってから再試行してください。
  • 会社ネットワークなどでダウンロードがブロックされる場合は、別の回線でセットアップした後、フォルダーごと移動する方法もあります。

「DLL が見つかりません」系のエラーが出る

Visual C++ 再頒布可能パッケージ（x64）が必要です。

  1. Microsoft の再頒布可能パッケージ を開きます。
  2. X64 のインストーラーをダウンロードして実行します。

チャットができない

状態が「OK」にならない

  • ⚙ 設定 → モデル タブの実行状態を確認してください（チャット画面の右下にも表示されます）。
  • llama-server の起動に時間がかかることがあります（特に初回・大きいモデル）。数分待ってから確認してください。
  • 他のAIアプリやサーバーアプリが動いている場合は終了してください。改善しない場合は PC を再起動してください。

返答が極端に遅い

  • CPU のみで動作している可能性があります。設定画面の モデル タブで実行バックエンド（CUDA / Vulkan / CPU など）を確認してください。
  • メモリ不足の場合は、より小さいモデル（量子化レベルの高い GGUF）をお試しください。設定 → モデル で追加モデルフォルダや別の GGUF を選べます。

モデルが一覧に出ない・切り替わらない

  • 設定 → モデル の「追加モデルフォルダ」は読み取り専用です。ファイルをアプリフォルダへ移す必要はありません。
  • モデル変更後は モデルを適用（llama 再起動） を押してください。
  • vision 用 mmproj が必要な場合、外部フォルダに無ければ アプリ側の models\ に取得されます。

設定画面のタブ

  • 基本設定・モデル選択・キャラクター設定・RAG・このアプリについての 5 つは常に表示されます。長期記憶のトグルは基本設定内にあります。
  • VOICEVOX タブは、VOICEVOX をインストール済みのときだけ表示されます（未インストール時は表示されません）。
  • バージョン番号・ライセンス・ログ・バックアップは 設定 → このアプリについて にあります。

長期記憶

  • 設定 → 基本設定 で「長期記憶を使う」をオンにします。記憶は名前付きキャラごとに分かれており、デフォルト AI には長期記憶はありません。
  • 記憶は PC 内に短い文として保存され、そのキャラとの会話の途中で自然に思い出して返すことがあります。画面上の一覧や手動追加はありません（内部保存のみです）。
  • 「会話終了時に自動で記憶を抽出」をオンにすると、名前付きキャラの会話を終えるときやアプリを閉じるときに、ローカル AI がそのキャラ用へ 0〜3 件を内部保存します。同じ会話内の直前のやり取りは、チャットの 履歴 オプションが担当します。
  • 記憶が使われないときは、記憶がオフになっていないか、名前付きキャラとの会話で十分な往復があるかをご確認ください。

キャラクターを切り替えたとき

  • キャラクターを切り替えると 新しい会話 になります。直前のセッションに別キャラの発言が混ざることはありません。
  • 以前の会話を続けるときは、左ペインの履歴から該当セッションを選んでください。

音声入力が使えない

  • 設定 → 基本設定 で「音声入力を使う」をオンにしてください。
  • Windows の 設定 → プライバシーとセキュリティ → マイク で、デスクトップアプリのマイク利用が許可されている必要があります。オフのときはチャットに案内が表示されます。
  • チャット入力欄横の マイク ボタンを押すと認識を開始します。もう一度押すと終了します（1 回の認識が終わると自動で終了することもあります）。
  • マイクが接続されていない、または他のアプリがマイクを占有している場合は認識できません。
  • 英語 UI でも、英語の音声認識パックが未導入の場合は日本語で聞き取ることがあります。英語で話す場合は Windows の設定で英語の音声認識を追加してください。
  • 音声入力のあと VOICEVOX の読み上げ音量が小さく感じる場合は、LocalCompanion を再起動するか、もう一度お試しください。

読み上げ（VOICEVOX）が動かない

  • VOICEVOX は別途インストールが必要です（https://voicevox.hiroshiba.jp/）。
  • 未インストール時は設定に VOICEVOX タブは表示されません。 インストール後に LocalCompanion を再起動するか、設定画面を開き直してください。
  • 設定 → VOICEVOX で「読み上げを有効」にし、話者を選ぶと自動で保存されます。
  • インストール済みでも、ポート 50021 を他のアプリが使用していると接続できません。
  • 標準以外の場所にインストールした場合は、VOICEVOX を先に起動してから LocalCompanion を起動してください。
  • 読み上げが動かなくても、チャットなど他の機能は通常どおり使えます。

チャットの挙動

  • デフォルト AI（キャラ未選択）の会話は、左の履歴一覧に表示されません。
  • チャットの オプション で 推論 をオフにすると、応答が安定しやすい場合があります。
  • 履歴 をオフにすると、過去のやり取りをモデルに渡しません。
  • URL 添付の取得上限は 2 MB です（RAG 取込とは別の上限です）。

画像入力（Vision）が失敗する

  • 本体 GGUF と mmproj ファイルの組み合わせが一致している必要があります。
  • 設定画面の モデル タブで、mmproj が設定されているかを確認してください。
  • チャットの 画像を挿入 が無効なときは、mmproj 未設定・非対応モデルなどが考えられます（実行状態の「OK」だけでは vision 可否は分かりません）。

RAG（資料検索）が動かない

  • 資料の登録・検索には llama-server の埋め込み API を使用します。状態が「OK」になってからお試しください。
  • 既定では 1 ファイル最大約 32 MB、フォルダー取り込みは最大 500 ファイルです。appsettings.json の RagMaxFileBytes（バイト）と RagMaxFolderFiles（件数）で変更できます（0 以下は無制限）。

プライバシーとネットワーク

  • 会話・RAG・添付の本文処理は PC 内で完結します。
  • 任意の更新確認で GitHub にアクセスすることがあり、VOICEVOX 利用時は VOICEVOX の更新確認でも GitHub にアクセスすることがあります。
  • 初回セットアップや mmproj 取得では Hugging Face 等へアクセスすることがあります。
  • URL 読み込み時や、メッセージ内の URL・調査意図による Web 検索時は、その先のサイトへアクセスします。既定の Web 検索は DuckDuckGo（HTML）で、検索語がそのサービスへ送られます。appsettings.json の WebSearchEnabled を false にするとオフにできます。
  • 音声入力は Windows の音声認識を使うため、環境によってはオンライン認識になることがあります。

ログの場所

問題を報告いただく際は、ログを添えていただくと原因の特定が早くなります。

起動方法ログ・データの場所
LocalCompanion.exe（通常）{LocalCompanion.exe のあるフォルダー}\data\
data\ に書き込めない場合%LocalAppData%\LocalCompanionLlama\

実際の場所は、設定 → このアプリについて → ログフォルダーを開く で確認できます。

データのバックアップと復元

  • 設定 → このアプリについて → データをバックアップ で、会話・RAG・設定を 1 つの ZIP に書き出せます。
  • 復元するときは、アプリを終了した状態で、書き出した ZIP の中身を上記のデータフォルダーに上書き展開してください。

それでも解決しないとき

  1. アプリを終了します。
  2. LocalCompanion フォルダー内の tools\llama-cpp\ フォルダーを削除します（次回起動時に再取得されます）。
  3. それでも改善しない場合は、設定画面からデータをバックアップしたうえで data\ フォルダーを別の場所へ移動し、初期状態で起動をお試しください。
